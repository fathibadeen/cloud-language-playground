# لوحة المشرف: قائمة جانبية وعرض الشركات وتعديلها بوضوح

## المشكلة الحالية
- لوحة المشرف بلا قائمة جانبية، وكل شيء داخل تبويبات صغيرة أعلى الصفحة.
- صفحة تفاصيل الشركة موجودة، لكن الوصول لها فقط بالضغط على اسم الشركة (غير واضح)، ولا تحمل قائمة جانبية.

## ما سيتغير
1. **قائمة جانبية ثابتة للمشرف** (ظاهرة دائمًا على الكمبيوتر، ومنسدلة بزر على الجوال) تضم:
   - نظرة عامة (الإحصاءات)
   - الشركات
   - WhatsApp
   - طلبات الربط
   - الويب هوك
   - العودة للوحة التحكم + تبديل اللغة
   نفس القائمة تظهر في صفحة تفاصيل الشركة.
2. **قسم الشركات** يصبح جدولًا واضحًا لكل شركة: الاسم، النشاط، المدينة، المنتج (واتساب/مكالمات/الاثنين)، الباقة، حالة الاشتراك، الحالة، عدد العملاء والمستندات والوكلاء، تاريخ التسجيل، وزر بارز **«عرض وتعديل»**، مع بحث وفلترة حسب الحالة والمنتج.
3. **صفحة تفاصيل الشركة** (الموجودة) تبقى بتبويباتها الحالية: بيانات الشركة للتعديل، العملاء، قاعدة المعرفة، الوكلاء، المحادثات والمكالمات، الفريق، السجل — داخل القائمة الجانبية الجديدة.

## خارج النطاق
لا تغيير على منطق ربط واتساب، أو طلبات الربط، أو لوحة العميل، أو البيانات نفسها.

## تفاصيل تقنية
- مكوّن `AdminShell` مشترك (sidebar + header) في `src/components/AdminShell.tsx`، بنفس نمط إصلاح قائمة لوحة العميل (`hidden md:block` + overlay للجوال).
- `admin.tsx`: الأقسام تُدار عبر search param `?section=` بدل التبويبات، مع روابط القائمة إليها؛ صفحة `admin_.companies.$companyId.tsx` تُلفّ بـ `AdminShell`.
- `getPlatformOverview`: إضافة عدّادات لكل شركة (customers, knowledge_documents, ai_agents) وحقول voice_enabled/whatsapp_enabled.
